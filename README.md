## 📋 프로젝트 소개

플라이 낚시를 사랑하는 낚시인을 위한 타잉 소품 및 장비 리뷰 아카이브입니다. 실제 사용 경험을 바탕으로 한 상세한 리뷰와 팁을 제공합니다.

### 🌐 웹사이트 보기
**👉 [https://caddis-gr.github.io/fishing-gear/](https://caddis-gr.github.io/fishing-gear/)**

## ✨ 주요 기능

- 🎨 **깔끔한 카드 디자인** - 브랜드별 색상으로 구분된 시각적 레이아웃
- 🔍 **실시간 검색** - 브랜드, 제품명으로 빠른 검색
- ⭐ **평점 시스템** - 5점 만점 별점 평가
- 📱 **반응형 디자인** - 모바일, 태블릿, PC 모두 지원
- 📊 **통계 대시보드** - 전체 리뷰 수, 브랜드 수, 평균 평점 표시


## 📝 새 리뷰 추가하는 방법

### 1단계: 리뷰 HTML 파일 생성
```bash
# reviews 폴더에 새 HTML 파일 생성
cd reviews
cp 기존파일.html 새파일.html
```

### 2단계: 내용 수정
- 제품명, 브랜드, 설명 수정
- 상세 리뷰 작성
- 이미지 추가 (선택사항)

### 3단계: index.html 업데이트
메인 페이지의 카드 그리드에 새 카드 추가:

```html

      <span class="text-2xl">🎣</span>
    </div>
    <h3 class="text-2xl font-bold text-slate-800 mb-2">제품명</h3>

    </div>

       class="inline-block w-full text-center px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 transition">

    </a>
  </div>

```

### 4단계: GitHub에 업로드

```bash
git add .

git push origin main
```

## 🌟 최신 리뷰

### SA Sonar Stillwater Parabolic Sink WF5S (2026.04) 🆕
전 수심층을 빠르게 탐색하는 파일럿 기능 위주로 설계된 라인이지만, 느린 8자 리트리브로 운영한다면 전혀 다른 성격의 라인으로 바뀐다. Sink 5의 밸리가 Sink 3의 팁보다 먼저 떨어지면서 U자 형태가 만들어지고, 뒤따르는 플라이가 이 궤적을 그대로 따라 움직이게 된다. 떨어지면서 전층을 통과하고, 바닥을 탐색하고, 다시 수직으로 올라오는 — 하나의 캐스팅으로 다양한 수층 궤적을 만들어내는 라인이다.

**핵심 특징:**
- 🔵 **Sink 3/5/3** — 런닝(Sink 3) · 헤드(Sink 5) · 팁(Sink 3) · Seamless Density
- 📐 **U형 침강** — Sink 5 밸리가 먼저 바닥에 안착, 팁·플라이가 순서대로 뒤따름
- 🪰 **Larva 바닥권 운용** — 싱킹라인 조건에서 Chironomid Larva를 바닥 바로 위에 띄우는 것이 가능
- 📏 **Head 35.5ft / 10.8m** — 오버웨이트 +2 설계, 멀티플라이·긴 리더 캐스팅 용이
- 🎯 **수직상승** — 발 앞 수직상승 구간에서 Pupa 우화에 가까운 프레젠테이션

### T&T Helix 863-4 (2026.04) 🆕
처음으로 작정하고 고른 드라이플라이 전용 로드. T&T 미디엄 계열 빈티지 클래식으로, Paradigm과 같은 DNA를 가지면서 더 가볍고 더 섬세한 #3 피네스 피싱의 세계를 열어준다. 관리형 낚시터 표층권 피네스 피싱(& 마이크로님핑)의 최적의 태클.

**셋업 구성:**
- 🎣 **로드**: T&T Helix 863-4 (#3 / 8'6" / Medium Action / Graphite)
- 🧵 **라인**: RIO Elite Technical Trout WF4F (오버라이닝 세팅)
- 📏 **티펫**: 6x~7x Fluorocarbon 2~3m
- 🪝 **플라이**: Chironomid Larva/Pupa #16~20 · Dry Fly

### Airflo Euro Nymph Short 22ft (2026.03) 🆕
예민한 송어를 꼬셔낼 방법으로, 루어낚시의 '네오스타일'에서 모티브를 얻은 채비. 표층·중층·바닥까지 전층을 공략 대상으로 하며, 바닥층을 집중적으로 노리는 구성.

**셋업 구성:**
- 🎣 **로드**: Vision Onki 3100-4 (10ft / #3 / 미디엄패스트)
- 🪝 **백킹라인**: RIO Technical Euro Nymph (불용 재활용)
- 📏 **롱리더**: 투톤 인디케이터 2X (1.5m) + 레벨리더 3X→4X→5X (각 2.0m) + 스위벨 도래 + 티펫 6X

### Airflo Sixth Sense 2 WF6·7 DI5 (2026.03)
도착 당일 첫 스트레칭에서 "엇?!!" — PVC 라인에 익숙한 탓인지 처음 당겼을 때 안 늘어나는 느낌이 강렬했습니다. 6% 저신장 PU 소재의 쫀쫀하고 딴딴한 물성. 풀싱킹 인벤토리 SUB A로 포지셔닝, Titan 3D i/3/5 대비 전 구간 균일 5ips 직선 침하의 차이가 조과로 이어지는지 비교 검증 예정.

**주요 스펙:**
- 🔵 **Sink 5 (5.0ips)** — 전 구간 균일 침하
- 📏 **Head 46ft** — Front Taper 20' + Belly 16' + Rear Taper 10'
- 💪 **Low Stretch 6%** — 경쟁사 PVC 대비 1/4 수준
- 🌿 **100% PVC Free** — Polyurethane, 1984년부터

### RIO Elite Sub-Surface CamoLux WF5I (2026.03)
카모 패턴으로 물속에서 라인의 존재감을 낮추는 인터미디어트 싱킹 라인. Scott Centric 690-4 + CamoLux WF5I 조합으로 맑은 수질 중층 스텔스 공략에 특화.

**주요 특징:**
- 🎯 1.5~2ips 인터미디어트 싱킹 — 수심 2~6ft 중층 정밀 공략
- 🌿 카모 컬러링(올리브/다크그린) — 맑은 수질 스텔스 효과
- 🔗 ConnectCore Plus 저신축 코어 — 중층에서도 어신 감지 용이
- 🎣 30ft 짧은 헤드 — 최소 폴스 캐스팅으로 빠른 재투척 가능
